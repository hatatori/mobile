AlertDialog

Uma caixa de diálogo é uma pequena janela que leva o usuário a tomar uma decisão ou inserir mais informações. Elas não ocupam toda a tela e são normalmente usadas para eventos modais que exijam que usuários realizem uma ação antes de continuar.

AlertDialog( onDismissRequest = { }, // ao clicar fora confirmButton = { }, text = { } )

Exemplo completo

@Composable fun AlertDialogExample1(){ var showDialog by remember { mutableStateOf(false) } Button(onClick = { showDialog = true }) { Text("Abrir") } if (showDialog) { AlertDialog( onDismissRequest = { showDialog = false }, confirmButton = { TextButton(onClick = { showDialog = false }) { Text("Confirmar") } }, text = { Text("Milkshake") } ) } }
