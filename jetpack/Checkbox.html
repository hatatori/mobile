Estrutura básica

Checkbox( checked = true, onCheckedChange = { } ) Text("Option 0")

Estrutura com estado

var checked by remember { mutableStateOf(true) } Row(verticalAlignment = Alignment.CenterVertically){ Checkbox( checked = checked, onCheckedChange = { checked = it } ) Text("Option 0") }

Múltiplos checks

val caixasStates = remember { mutableStateListOf(false, false, false) } caixasStates.forEachIndexed { index, checked -> Row( verticalAlignment = Alignment.CenterVertically, ) { Text("Valor ${index + 1}") Checkbox( checked = checked, onCheckedChange = { isChecked -> caixasStates[index] = isChecked } ) } } if(caixasStates[0]){ Text("Cat") } if(caixasStates[1]){ Text("Dog") } if(caixasStates[2]){ Text("Cow") }
