Button

O Button é um componente do Android usado para criar botões interativos, permitindo que o usuário execute uma ação ao clicar, como enviar dados, abrir uma tela ou realizar uma operação.

<Button android:id="@+id/btn" android:layout_width="match_parent" android:layout_height="match_parent" android:text="Entrar" android:textSize="16sp" android:textColor="@android:color/white" android:backgroundTint="#2196F3" android:drawableStart="@drawable/ic_login" />
Button botao = findViewById(R.id.btn); botao.setOnClickListener(v -> { String nome = editTextNome.getText().toString(); Toast.makeText(this, "Olá, " + nome, Toast.LENGTH_SHORT).show(); });

<EditText/>

O EditText ( TextField ) é um componente do Android usado para permitir que o usuário digite e edite textos na tela, possibilitando personalizar aspectos como tipo de entrada, tamanho da fonte, cor, texto de exemplo e estilo.

<EditText android:id="@+id/editTextText2" android:layout_width="wrap_content" android:layout_height="wrap_content" android:ems="10" android:inputType="text" android:hint="Digite seu nome" />
EditText nome = findViewById(R.id.editTextNome); String texto = nome.getText().toString();
