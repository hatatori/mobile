Método

Um método é um bloco de código que executa uma tarefa específica com ou sem retorno.

public void DizerMarca(){ System.out.println("Eu sou da marca Toyota"); }

Um método deve está contido dentro de uma classe.

public class Carro{ public void DizerMarca(){ System.out.println("Eu sou da marca Toyota"); } }

A variável `carro` recebe a referência de um novo objeto Carro, que é instanciado pelo `new Carro()`.

A variável carro acessa o objeto Carro e executa o método DizerMarca().

Carro carro = new Carro(); carro.DizerMarca();

Métodos com parâmetro

Métodos com parâmetro são métodos que recebem valores como entrada para usar durante sua execução.

public class Matematica { public double soma(double a, double b){ return a+b; } public double subtracao(double a, double b){ return a-b; } public double multiplicacao(double a, double b){ return a*b; } public double divisao(double a, double b){ return a/b; } }
Matematica math = new Matematica(); Double n1 = math.soma(10, 10); Double n2 = math.subtracao(10, 10); Double n3 = math.multiplicacao(10, 10); Double n4 = math.divisao(10, 10); System.out.println( n1 ); // 20.0 System.out.println( n2 ); // 0.0 System.out.println( n3 ); // 100.0 System.out.println( n4 ); // 1.0

Abstração

Abstração é o princípio que consiste em esconder os detalhes complexos de implementação e mostrar apenas as funcionalidades essenciais de um objeto para quem vai utilizá-lo.

Na prática, significa criar um modelo simplificado da realidade, focando no que é relevante para o problema que você está resolvendo, e ignorando os detalhes desnecessários.

abstract public class Geometria { abstract double calcularArea(); abstract double calcularPerimetro(); }
public class Quadrado extends Geometria{ double lado; Quadrado(double lado){ this.lado = lado; } @Override double calcularArea() { return lado * lado; } @Override double calcularPerimetro() { return 4 * lado; } }
public class Circulo extends Geometria{ double raio; Circulo(double raio) { this.raio = raio; } @Override double calcularArea() { return Math.PI * this.raio * this.raio; } @Override double calcularPerimetro() { return 2 * Math.PI * this.raio; } }
Quadrado quadrado = new Quadrado(3); quadrado.calcularArea(); quadrado.calcularPerimetro(); Circulo circulo = new Circulo(5); circulo.calcularArea(); circulo.calcularPerimetro();

Herança

A herança permite que uma classe herde características e métodos de outra, facilitando a reutilização de código. Usa-se a palavra-chave extends.

class Animal { void comer() { System.out.println("Está comendo"); } }
class Cachorro extends Animal { void latir() { System.out.println("Au au!"); } }
class Gato extends Animal { void miar() { System.out.println("Miau!"); } } 
Animal
 ├── Cachorro
 └── Gato

gato e cachorro recebem o método .comer() herdada da classe Animal

Cachorro cachorro = new Cachorro(); Gato gato = new Gato(); cachorro.comer(); gato.comer(); cachorro.latir(); gato.miar();

Polimorfismo

Em Java, o polimorfismo permite que uma mesma referência seja usada para representar objetos de diferentes classes, fazendo com que o comportamento executado dependa do objeto real.

public class Cachorro extends Animal{ public void fazerSom() { System.out.println("Au au"); } }

public class Gato extends Animal { public void fazerSom() { System.out.println("Miau"); } }

As variáveis animal1 e animal2 têm o tipo Animal, mas executam o método da classe do objeto que realmente foi criado (Cachorro ou Gato).

Animal animal1 = new Cachorro(); Animal animal2 = new Gato(); animal1.fazerSom(); // Saída: AU AU animal2.fazerSom(); // Saída: MIAU

Composição

Composição é um conceito da Programação Orientada a Objetos em que uma classe possui um objeto de outra classe como parte de sua estrutura.

class Motor { void ligar() { System.out.println("Motor ligado!"); } }

A classe `Carro` recebe a classe `Motor`

class Carro { private Motor motor; public Carro() { motor = new Motor(); } void ligarCarro() { motor.ligar(); System.out.println("Carro ligado!"); } }

Carro carro = new Carro(); carro.ligarCarro();
