Estrutura de decisão

int idade = 20; if (idade >= 18) { System.out.println("Maior de idade"); }
int idade = 16; if (idade >= 18) { System.out.println("Maior de idade"); } else { System.out.println("Menor de idade"); }
int nota = 8; if (nota >= 9) { System.out.println("Excelente"); } else if (nota >= 7) { System.out.println("Aprovado"); } else if (nota >= 5) { System.out.println("Recuperação"); } else { System.out.println("Reprovado"); } // nota >= 9 → Excelente // nota >= 7 → Aprovado // nota >= 5 → Recuperação // senão → Reprovado
String login = "admin"; String password = "1234"; if (login.equals("admin") && password.equals("1234")) { System.out.println("Login realizado com sucesso!"); } else { System.out.println("Login ou senha incorretos."); }
int opcao = 2; switch (opcao) { case 1: System.out.println("Cadastrar"); break; case 2: System.out.println("Consultar"); break; case 3: System.out.println("Excluir"); break; default: System.out.println("Opção inválida"); }

Arrays

Um array é uma estrutura que guarda vários valores do mesmo tipo em uma única variável.

int[] numeros = {10, 20, 30, 40, 50}; ou int[] numeros = new int[]{10, 20, 30, 40, 50};

Percorrendo um array

int[] numeros = {10, 20, 30, 40}; for (int i = 0; i < numeros.length; i++) { System.out.println(numeros[i]); } // ou for (int numero : numeros) { System.out.println(numero); }

Mutabilidade

// Lista imutável List<String> names = List.of("Dog", "Cat", "Bird", "Dog"); // Lista mutável List<String> names = new ArrayList<>(List.of("Dog", "Cat", "Bird", "Dog")); // Acessar elemento names.get(0); // "Dog" names.get(1); // "Cat" names.size(); // 4 names.isEmpty(); // false // Pesquisa names.contains("Dog"); // true names.indexOf("Cat"); // 1 names.indexOf("Bear"); // -1 names.lastIndexOf("Dog"); // 0 // Criar nova lista List<String> upper = names.stream().map(String::toUpperCase).toList();

Classe

Uma classe em Java é um molde para criar objetos.

public class NomeDaClasse { // atributos // construtor // métodos }

Abaixo uma classe completa.

public class Pessoa { // Atributos String nome; int idade; // Construtor public Pessoa(String nome, int idade) { this.nome = nome; this.idade = idade; } // Método public void apresentar() { System.out.println("Olá, meu nome é " + nome); System.out.println("Tenho " + idade + " anos."); } }

Criando um objeto da classe Pessoa.

Pessoa pessoa1 = new Pessoa("Ana", 20); Pessoa pessoa2 = new Pessoa("Renata", 20); Pessoa pessoa3 = new Pessoa("Ana", 20); pessoa1.apresentar(); pessoa1.apresentar(); pessoa1.apresentar();
