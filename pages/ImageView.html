<ImageView/>

ImageView é um componente do Android usado para exibir imagens na tela. Você pode especificar a imagem através do atributo `android:src`

Bordas arredondadas ( ShapeableImageView )

É um componente que permite desenhar imagens com formas personalizadas, cantos arredondados, cortes ou bordas de forma simples e direta no XML.

<com.google.android.material.imageview.ShapeableImageView android:id="@+id/imageView" android:layout_width="100dp" android:layout_height="100dp" android:src="@drawabsle/avatar" android:scaleType="centerCrop" app:shapeAppearanceOverlay="@style/CircularImageView" />
<style name="CircularImageView"> <item name="cornerFamily">rounded</item> <item name="cornerSize">50%</item> </style>
Image( painter = painterResource(R.drawable.minha_imagem), contentDescription = null, modifier = Modifier .size(120.dp) .clip(RoundedCornerShape(16.dp)), contentScale = ContentScale.Crop )
Image( painter = painterResource(R.drawable.minha_imagem), contentDescription = null, modifier = Modifier .size(120.dp) .clip( RoundedCornerShape( topStart = 20.dp, topEnd = 20.dp, bottomStart = 0.dp, bottomEnd = 0.dp ) ), contentScale = ContentScale.Crop )

Imagem da web

Para que o aplicativo possa trocar informações com a internet, é necessário realizar uma configuração no arquivo `AndroidManifest.xml`

<uses-permission android:name="android.permission.INTERNET" />

Adicione a dependência abaixo no `build.gradle.kts`

Isso é a dependência do Glide no seu projeto Android: Ela permite carregar imagens da internet

implementation("com.github.bumptech.glide:glide:4.16.0")
