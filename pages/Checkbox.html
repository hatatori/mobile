Checkbox

CheckBox é um elemento de interface que permite ao usuário selecionar uma ou mais opções independentes com dois estados possíveis: marcado ou desmarcado (true ou false).

<CheckBox android:id="@+id/checkBox" android:layout_width="wrap_content" android:layout_height="wrap_content" android:text="Cebola" />
var cebolaSelecionada by remember { mutableStateOf(false) } Checkbox( checked = cebolaSelecionada, onCheckedChange = { cebolaSelecionada = it } )

.setOnCheckedChangeListener() - Evento de mudança

CheckBox checkBox = findViewById(R.id.checkBox); checkBox.setOnCheckedChangeListener((v, isChecked)->{ ... }); if(checkBox.isChecked()){ ... }
val checkBox = findViewById<CheckBox>(R.id.checkBox) // evento de mudança checkBox.setOnCheckedChangeListener { buttonView, isChecked -> ... } // verificar se está marcado if (checkBox.isChecked) { ... }
