Imagem

Usado para exibir imagens na tela. Você pode especificar a imagem através do atributo android:src

Image( painter = painterResource(R.drawable.my_image), contentDescription = "Desc", modifier = Modifier.size(100.dp) )
AsyncImage( model = "https://exemplo.com/foto.jpg", contentDescription = "Desc", modifier = Modifier.size(100.dp) )

Arredondamento

O `.clip()` é a tem a função de arredondamento

Arredonda todos os vértices

Image( painter = painterResource(R.drawable.minha_imagem), contentDescription = null, modifier = Modifier .size(120.dp) .clip(RoundedCornerShape(16.dp)), contentScale = ContentScale.Crop )

Arredonda vértices de forma individual

Image( painter = painterResource(R.drawable.minha_imagem), contentDescription = null, modifier = Modifier .size(120.dp) .clip( RoundedCornerShape( topStart = 20.dp, topEnd = 20.dp, bottomStart = 0.dp, bottomEnd = 0.dp ) ), contentScale = ContentScale.Crop )

Linha e Coluna

`Row` e `Column` são usados para organizar elementos

Linha ( Um elemento abaixo do outro )

Row(){ Text("Cat") Text("Dog") Text("Fox") }

Coluna ( Um elemento do lado do outro )

Column(){ Text("Cat") Text("Dog") Text("Fox") }

AlertDialog

AlertDialog

Uma caixa de diálogo é uma pequena janela que leva o usuário a tomar uma decisão ou inserir mais informações. Elas não ocupam toda a tela e são normalmente usadas para eventos modais que exijam que usuários realizem uma ação antes de continuar.

AlertDialog( onDismissRequest = { }, // ao clicar fora confirmButton = { }, text = { } )

Exemplo completo

@Composable fun AlertDialogExample1(){ var showDialog by remember { mutableStateOf(false) } Button(onClick = { showDialog = true }) { Text("Abrir") } if (showDialog) { AlertDialog( onDismissRequest = { showDialog = false }, confirmButton = { TextButton(onClick = { showDialog = false }) { Text("Confirmar") } }, text = { Text("Milkshake") } ) } }
