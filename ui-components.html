UI components

São os elementos visuais que você coloca na tela de um aplicativo para o usuário ver e interagir.

  • 🔘 Button -> botão
  • 📝 EditText / TextInput -> campo para digitar
  • ☑️ CheckBox -> caixa de seleção
  • 🔘 RadioButton -> seleção única
  • 🎚️ Switch -> liga/desliga
  • 📋 RecyclerView -> lista de itens
  • 🖼️ ImageView -> imagem
  • 📑 TextView -> texto
  • 🧭 Toolbar -> barra superior
  • 🪟 Dialog -> janela de diálogo
