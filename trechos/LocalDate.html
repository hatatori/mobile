LocalDate

YYYY-MM-DD

LocalDate hoje = LocalDate.now(); LocalDate nascimento = LocalDate.of(2000, 5, 15); nascimento.getYear(); nascimento.getMonth(); nascimento.getMonthValue(); nascimento.getDayOfMonth();

Somando e subtraindo datas

LocalDate hoje = LocalDate.now(); LocalDate diaProximo = hoje.plusDays(1); LocalDate mesProximo = hoje.plusMonths(1); LocalDate anoProximo = hoje.plusYears(1); LocalDate diaPassado = hoje.minusDays(1); LocalDate mesPassado = hoje.minusMonths(1); LocalDate anoPassado = hoje.minusYears(1);

Comparando datas

LocalDate hoje = LocalDate.now(); LocalDate futuro = hoje.plusDays(10); hoje.isBefore(futuro); // true hoje.isAfter(futuro); // false hoje.isEqual(futuro); // false
