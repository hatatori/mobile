Classe

Uma classe em Java é um molde para criar objetos.

public class NomeDaClasse { // atributos // construtor // métodos }

Abaixo uma classe completa.

public class Pessoa { // Atributos String nome; int idade; // Construtor public Pessoa(String nome, int idade) { this.nome = nome; this.idade = idade; } // Método public void apresentar() { System.out.println("Olá, meu nome é " + nome); System.out.println("Tenho " + idade + " anos."); } }

Criando um objeto da classe Pessoa.

Pessoa pessoa1 = new Pessoa("Ana", 20); Pessoa pessoa2 = new Pessoa("Renata", 20); Pessoa pessoa3 = new Pessoa("Ana", 20); pessoa1.apresentar(); pessoa2.apresentar(); pessoa3.apresentar();
